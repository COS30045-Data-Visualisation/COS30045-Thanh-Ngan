About this website

This website was built to help people understand how much electricity common household appliances use in Australia, and what that use costs over time.

Purpose of this site

This site is a small demonstration project created for COS30045 Data Visualisation at Swinburne University of Technology. It shows how a simple multi-page website can be structured with HTML, styled with CSS, and made interactive with JavaScript. It also serves as the foundation for later exercises, where real appliance energy data will be visualised.

Built with

  • HTML page structure and content
  • CSS layout, colours and consistent styling across pages
  • JavaScript interactive features such as the FAQ accordion
  • Git and GitHub version control and project hosting

Related information

This website was created for Exercise 0.2 in a unit named COS30045 Data Visualisation.

Small note on the Data

The figures and descriptions on this website are placeholders used to demonstrate page structure and interactivity. They are not official statistics. Real appliance energy data will be introduced in later exercises.
